# 库存成本语义：移动加权平均、不允许负库存、红冲按原单

T2 定稿（2026-08-12 访谈逐项确认），衔接 R1 调研事实与 T1 表结构（cost 快照列、ref_id、opening_stock 基线）。

## 加权平均公式与触发时机

单位成本 =（进货前结存金额 + 本次进货金额）÷（进货前结存数量 + 本次进货数量）。

- **只有进货触发重算**；售出按当时加权均价快照成本出库，本身不改变均价（移动加权平均的定义性特征）。
- 期初库存（opening_stock）为首笔结存基数；无期初时公式退化为本次进货单价。

## 不允许负库存（业务纪律，非系统闸门）

业务上不会发生「先卖后进」：主人不会卖没有的货（人的因素）。因此系统**不设负库存闸门**，也无暂估/校正分支——售出成本快照一律取当时加权均价。

记录层面库存不足（漏录期初/进货，实物有货）时：不硬拒，靠**补录修正**记录（与 0003 新商品出货归零补录同思路），日报异常提醒兜底。

## 红冲（进货退货/售出退货）

红冲**必须关联原单**（transactions.ref_id），按原单成本冲；**退货价 = 原单价格**（售出退货退原售出价、进货退货按原进货价），不引入第三方价格——天然避开「退货价≠原价 → 结存单价异常」。

- **进货退货**：数量与金额按原进货单价红字冲减，结存均价随之重算；不直接冲减当期毛利（只减少后续可售成本）。
- **售出退货**：按原售出单的成本快照把货退回库存（数量、金额按快照恢复），均价重算；收入与成本同步冲减，毛利按该笔减少。
- **换货** = 红冲原单 + 新录一张。
- 红冲致记录为负不硬拒（同「不允许负库存」原则：人在场判断）。

历史已结转成本不回滚（与 0001 派生值现算一致：状态由事实推导）。

## 毛利口径

毛利 = 收入 − 快照成本（amount = qty × price 现算，cost 为售出时快照，无额外扣减）。售出退货冲减当期毛利；进货退货不直接冲。

## 进货运费入账口径（T7 定稿，2026-08-13）

- **当期费用化（不算成本）**：小企业准则第六十五条批发/零售业口子（进货运输费归销售费用）有明确依据。运费**不进**加权平均成本（公式分子分母不含 freight）、不影响毛利、无需按产品分摊。
- **售出运费不计入毛利扣除项**：毛利维持「收入 − 快照成本」；售出运费属期间费用，与进货运费一样单列求和展示（T5 展示侧约定一致）。
- **一票多产品共担运费不做分摊**：整票运费记在本次进货第一笔流水（或主人口述明说的那笔）的 freight，其余流水为 0；运费合计 = 全部流水 freight 求和，口径不变。
