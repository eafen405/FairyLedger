# 新商品出货自动补录等量期初归零

T3 定稿：录售出时发现库中没有该商品（实际有货只是未建档/未录期初），Fairy 确认建档后**自动补录一笔数量等于出货量的期初库存**，使该商品当前库存归零，而不是显示负数。

例：实际有 5 件未录 → 卖 3 件发现无档案 → 自动补录期初 3 → 库存 0 → 之后盘点补录剩余 2 → 库存 2，与实物一致。

原因是主人实际场景中"没建档 = 有货只是没录"，显示负库存反而是假象。与 T2 定稿库存纪律（ADR 0004）的关系：**不允许负库存**——业务上不发生（没货不会卖，人判断），系统不设闸门；新商品首次出货走归零补录，与整体纪律一致。此决策导致期初库存不再"只录一次"——补录型期初（归零）与启用型期初（一次性）并存，审计日志需覆盖归零补录。
