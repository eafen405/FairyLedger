# R1 成本核算惯例调研

> 用途：为 v4 规格的成本核算基线（进货必录进价、移动加权平均、每笔售出快照当时成本、报告含完整毛利；红冲=退货；期初不进流水）收集事实依据，供 grilling ticket 决策。本文件只陈述事实与来源，不做设计决策。
> 核验说明：关键一手来源（CAS 1、小企业准则、CAS 14、《会计基础工作规范》）均亲自打开原文核对；教材/ERP 类为转述或产品文档，已在条目内注明。

## 1. 移动加权平均成本

### 惯例结论
1. 标准公式：存货单位成本 =（本次进货前结存金额 + 本次进货金额）÷（本次进货前结存数量 + 本次进货数量）；每次进货后**立即**重算，是移动加权平均法区别于月末一次加权平均的定义性特征 [S1.1][S1.2]。
2. 准则只列「先进先出法、加权平均法或者个别计价法」[S1.3][S1.4]，无「移动加权平均」字样；通行解释（CPA 教材）将加权平均法理解为含移动加权平均 [S1.5]。小企业准则第十三条同款，且「计价方法一经选用，不得随意变更」[S1.4]。
3. 负库存（先卖后进）：**无权威定论**——准则隐含账实一致、先取得再发出，CAS 1 无相关条文。实务惯例：发票未到的先卖后进做**月末暂估入账、下月初冲回** [S1.6]；ERP 对负库存导致的出库无成本按「零成本单据取价」（暂估/最近成本）处理 [S1.7]。
4. 补录进货后**不校正**此前已快照的成本：小企业准则规定会计差错更正一律用未来适用法（只在发现当期及以后调整）[S1.4]；企业会计准则仅在「重要前期差错」时用追溯重述法（CAS 28）[S1.8]。ERP 惯例是重算出库成本并对已结账单据补差生成成本调整单，不修改历史 [S1.7]。

### 来源
- [S1.1] 东奥会计在线《移动加权平均法公式是什么》 https://www.dongao.com/zckjs/kj/202105263451461.shtml — 「(本次进货之前库存存货的实际成本＋本次进货的实际成本)/(本次进货之前库存存货数量＋本次进货的数量)」「在每次收货以后，立即根据库存存货数量和总成本，计算出新的平均单位成本」。
- [S1.2] 正保会计网校《初级会计实务知识点：加权平均法》 https://www.chinaacc.com/chujizhicheng/fxzd/wa20191230140121.shtml — 教材口径：以每次进货成本加原有库存成本，除以每次进货数量与原有库存数量之和。
- [S1.3] 财政部《企业会计准则第1号——存货》（财会[2006]3号） https://www.casc.org.cn/2018/0815/202816.shtml — 第十四条「企业应当采用先进先出法、加权平均法或者个别计价法确定发出存货的实际成本」（计价方法条款是第十四条，第十九条是跌价准备转回）。
- [S1.4] 财政部《小企业会计准则》（财会[2011]17号，政府网公报） https://www.gov.cn/gongbao/content/2012/content_2121709.htm — 第十三条计价方法＋不得随意变更；第八十八条「会计政策变更、会计估计变更和会计差错更正应当采用未来适用法进行会计处理」。
- [S1.5] 中大网校《2010年CPA〈会计〉辅导：存货发出的计价》 https://www.wangxiao.cn/cpa/377552152337.html — 「加权平均法(包括移动加权平均法)」通行表述。
- [S1.6] 正保会计网校问答《未收到发票先卖出去，结转当月成本是否先暂估》 https://www.chinaacc.com/wenda/detail/xt/1861545 — 先卖后进、发票未到：暂估入账并结转成本，收到发票后红冲调整。另有会计学堂同口径问答： https://www.acc5.com/ask/question_1661624.html
- [S1.7] 金蝶云官方文档《出库成本核算》 https://help.open.kingdee.com/dokuwiki/doku.php?id=出库成本核算 — 「零成本单据自动取价……主要解决……负库存导致的无出库成本」；已生成凭证的单据重算时「补差生成成本调整单」或差异结转期末余额。
- [S1.8] 财政部《企业会计准则第28号——会计政策、会计估计变更和差错更正》 https://www.casc.org.cn/2018/0815/202779.shtml — 重要的前期差错应当采用追溯重述法更正。
- 附注（美税口径）：IRS Publication 538 (01/2022) https://www.irs.gov/publications/p538 存货章节的识别方法仅 Specific Identification / FIFO / LIFO，**无加权平均/移动平均法**——该口径在美税体系无据。

### 对 v4 设计的含义
- 「每笔售出快照当时加权平均成本」与教材定义一致（发出时按当时结存单价计算）；公式的分子分母均只含「进货前结存 + 本次进货」，不含其他项。
- 负库存场景的售出成本取值无准则依据，只能是系统自定（如暂估/最近成本）；历史快照事后不因补录进货而校正属普遍惯例，并有小企业准则未来适用法背书。

## 2. 红冲/退货对库存与成本的影响

### 惯例结论
1. 采购退货：准则**无专门条文**（CAS 1 全文无「退货」二字）。实务惯例：按退回数量 × 原采购入库单价红字冲减存货数量与金额，并重新计算加权平均单价（当期冲减+重算，不修改历史已结转成本）[S2.1][S2.2]。退货价≠原单价致结存单价异常（如负单价）时，ERP 惯例改按当前结存单价冲减、差额挂「库存调整」科目 [S2.3]。
2. 销售退货：小企业准则第六十一条——已确认收入的售出商品退回「应当在发生时冲减当期销售商品收入」（不论本年度还是以前年度）[S2.4]；教材口径为同时冲减当期销售收入与销售成本，退回商品按**原售出（已结转）成本**重新入库（借库存商品、贷主营业务成本）[S2.5]。
3. 附有销售退回条款的销售（预计退货）：CAS 14 第三十二条——预期退回商品按「转让时的账面价值」确认为资产、按转让账面价值扣减该资产的净额结转成本，即按原转让价值计量而非退回时点成本 [S2.6]。
4. 报表/税务口径：销售退回与折让从毛销售额中扣减（计净销售额），采购退回从全年采购额中扣减（IRS Pub 334）[S2.7]——与「冲减发生当期」方向一致。

### 来源
- [S2.1] 会计学堂问答《移动加权平均法计算成本，退货时成本怎么算》 https://www.acc5.com/ask/question_2295793.html — 公式含退货项＝(以前结存成本＋本批收入成本−采购退货成本)/(数量−退货数量)；采购退货按对应采购发票入库单价×数量红字冲减。
- [S2.2] 正保会计网校《初级会计实务归纳：采购退货的处理》 https://www.chinaacc.com/new/15_16_201211/05go1349694060.shtml — 按采购价冲减并调整单位成本；示例出现负单位成本。
- [S2.3] 同上 [S2.2] — ERP 实务按当前库存单位成本减库存、差额贷记「库存调整」科目。
- [S2.4] 财政部《小企业会计准则》第六十一条（同上 [S1.4] URL）— 「已经确认销售商品收入的售出商品发生的销售退回……应当在发生时冲减当期销售商品收入」。
- [S2.5] 东奥会计在线《2018初级会计实务知识点：销售退回》 https://m.dongao.com/c/2017-09-07/791904.shtml — 「应当在发生时冲减当期销售商品收入、销售成本等」，退回入库分录借库存商品贷主营业务成本。同口径见正保《存货成本计算中如何处理采购/销售退货》 https://m.chinaacc.com/chujizhicheng/jhwd/zy20251116023133.shtml
- [S2.6] 财政部《企业会计准则第14号——收入》（2017修订） https://kjs.mof.gov.cn/zt/kjzzss/kuaijizhunzeshishi/201709/t20170907_2694006.htm — 第三十二条：预期退回商品按转让时账面价值确认资产、净额结转成本。
- [S2.7] IRS Publication 334 (2025) https://www.irs.gov/pub/irs-pdf/p334.pdf — 「Sales returns and allowances…are deductions from gross sales in figuring net sales」「Purchase returns and allowances. You must deduct all returns and allowances from your total purchases」。
- 注：CAS 1 与《小企业会计准则》均无「红冲」或「退货」的计量/重算条文，第 1 条与第 2 条属教材与实务惯例。

### 对 v4 设计的含义
- 退货的库存与成本处理惯例是**按原单成本冲减**（采购退货按原采购价冲数量与金额、销售退货按原售出成本重新入库），随后加权平均单价被重算；不是按退货单价格冲减，也不是回滚历史快照。
- 「按原单成本冲减」隐含需要追溯原单（原采购入库价/原售出成本）——准则本身不要求关联原单，关联与否是系统能力问题。

## 3. 毛利口径（运费与退货）

### 惯例结论
1. 进货运费计入存货成本（主口径）：CAS 1 第六条——存货采购成本包括购买价款、相关税费、运输费、装卸费、保险费以及其他可归属于存货采购成本的费用 [S3.1]；小企业准则第十二条同款（不含可抵扣进项税）[S3.2]。
2. 但小企业（批发/零售）有明确的费用化口子：小企业准则第六十五条将「批发业、零售业在购买商品过程中发生的费用（运输费、装卸费、包装费、保险费、运输途中合理损耗、入库前挑选整理费等）」归入**销售费用**而非存货成本 [S3.2]；企业会计准则应用指南亦允许商品流通企业进货费用先归集、期末按存销比分摊，金额较小的可直接计入当期损益 [S3.3]。
3. 销售运费计入销售费用（期间费用）：小企业准则第六十五条（销售费用含运输费、装卸费等）[S3.2]；毛利＝营业收入−营业成本，销售费用只影响营业利润、**不计入毛利**（小企业准则第六十七条利润构成公式）[S3.2]。是否把销售运费从毛利中再扣减是企业管理口径选择，非准则要求。
4. 退货对毛利：销售退回同时冲减当期收入与成本，毛利按退回商品的毛利额相应减少 [S2.5][S3.4]；进货退回冲减存货（采购）成本，不直接冲减当期毛利，只减少可供销售成本、影响后续发出成本 [S3.4]。

### 来源
- [S3.1] 财政部《企业会计准则第1号——存货》第六条（同上 [S1.3] URL）— 采购成本含购买价款、相关税费、运输费、装卸费、保险费及其他可归属于存货采购成本的费用。
- [S3.2] 财政部《小企业会计准则》（同上 [S1.4] URL）— 第十二条外购存货成本；第六十五条「批发业、零售业在购买商品过程中发生的费用（运输费、装卸费、包装费、保险费、运输途中的合理损耗和入库前的挑选整理费等）也构成销售费用」；第六十七条营业利润＝营业收入−营业成本−营业税金及附加−销售费用−管理费用−财务费用＋投资收益。
- [S3.3] 《企业会计准则——应用指南》存货部分（镜像） https://www.jinchutou.com/shtml/view-419245446.html — 商品流通企业进货费用可先归集、期末按存销比分摊，「金额较小的，可以在发生时直接计入当期损益」。
- [S3.4] 《采购退换、销售退换财税处理》（镜像） https://www.jinchutou.com/shtml/view-559465546.html — 进货退回冲减存货成本；销售退回「均冲减退回当月的销售收入，同时冲减当月的销售成本」。

### 对 v4 设计的含义
- 「报告含完整毛利」若按收入−成本口径，销售运费天然不在毛利内；把销售运费计入毛利扣除项属自定义管理口径，两条路都有实务存在。
- 进货运费计入存货成本是主口径，但小企业（批发/零售）准则明确允许进货费用直接费用化——两种口径均有权威依据，需在决策中二选一或提供开关。

## 4. 期初库存（中途启用）

### 惯例结论
1. 准则无「期初余额如何录入」的正面规定：CAS 1 中「期初」仅出现于披露条款（第二十二条：披露各类存货的期初和期末账面价值）[S4.1]；《会计基础工作规范》只规定年度终了把各账户余额结转下年、新账第一行填「上年结转」余额 [S4.2]。
2. 概念支撑：期初余额是上期期末余额在持续经营前提下的延续（基本准则第六条），不构成本期交易或事项、不产生本期发生额——「期初一次录入、不进流水」与准则概念一致 [S4.3]。
3. 实务惯例（ERP 建账）：期初余额（＝启用期间上期期末数）与本年累计发生额分列录入，完成初始化、试算平衡后才开始日常账务处理 [S4.4]；期初结存是移动加权平均单价计算的期初基数 [S4.5]。
4. 无权威定论，惯例为「期初直接录入、不进流水」——找不到任何要求期初库存走交易流水的准则/规范条文 [S4.1][S4.2][S4.4]。

### 来源
- [S4.1] 财政部《企业会计准则第1号——存货》第二十二条（同上 [S1.3] URL）— 「各类存货的期初和期末账面价值」系全文唯一「期初」。
- [S4.2] 财政部《会计基础工作规范》（财会字〔1996〕19号，镜像） https://www.waizi.org.cn/law/6230.html — 第六十四条（三）「年度终了，要把各帐户的余额结转到下一会计年度……在下一会计年度新建有关会计帐簿的第一行余额栏内填写上年结转的余额」。
- [S4.3] 《企业会计准则——基本准则》（财政部令第33号） https://www.gov.cn/gongbao/content/2007/content_549050.htm — 第六条「企业会计确认、计量和报告应当以持续经营为前提」。
- [S4.4] 金蝶官方《财务初始余额如何快速录入？》 https://www.kingdee.com/article/1523968859797737474.html — 「年中启用账套，需要录入期初余额（即启用账套期间的上期期末数）、本年累计借方和本年累计贷方」。
- [S4.5] 东奥《移动加权平均法怎么计算》 https://www.dongao.com/cma/zy/202601044627402.html — 「(1)确定初始库存：记录期初结存商品的数量和金额」。

### 对 v4 设计的含义
- 「期初库存一次录入、不进流水」无准则正面条文，但符合期初余额＝上期末余额延续、不构成发生额的概念，且是 ERP 建账的通行做法。
- 期初结存的数量与金额是移动加权平均公式的期初基数：无期初时公式退化为「本次进货金额÷本次进货数量」。
